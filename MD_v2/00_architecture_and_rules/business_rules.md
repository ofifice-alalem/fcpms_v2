# قواعد العمل — المرجع الرسمي

> هذا الملف هو المرجع الأساسي. عند أي تعارض بين الكود والقواعد هنا، هذا الملف هو الصحيح.

---

## المستخدمون والأدوار

| # | القاعدة |
|---|---------|
| BR-001 | نوعان فقط من المستخدمين: `hr` و `consultant` |
| BR-002 | لكل مستخدم حساب واحد فقط |
| BR-003 | حالة الاستشاري: `active` / `inactive` / `vacation` |
| BR-004 | المستخدم `inactive` لا يستطيع تسجيل الدخول |
| BR-005 | HR يمكنه تعديل أو إيقاف أو تفعيل أي استشاري |

## جداول العمل

| # | القاعدة |
|---|---------|

| BR-009 | يمكن أن تختلف الجداول بين الاستشاريين |
| BR-010 | إذا لم يكن اليوم ضمن الجدول → لا يُحسب غياباً |

## المهام — عام

| # | القاعدة |
|---|---------|
| BR-027 | نوعان: `daily` (يومية) و `on_demand` (حسب الحاجة) |
| BR-028 | HR فقط ينشئ/يعدل/يعطل المهام |
| BR-029 | الاستشاري لا يستطيع إنشاء أو تعديل أو حذف مهمة |

## ظهور المهام (Visibility)

| BR-038 | إذا خُصصت لمواقع → لا تظهر إلا في تلك المواقع |
| BR-039 | إذا لم يُختر موقع أو استشاري → المهمة عامة |

## الصور والنصوص
