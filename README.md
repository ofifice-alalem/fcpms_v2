## 🎯 الرؤية العامة

**FCPMS** هو نظام متكامل لإدارة وتقييم أداء الاستشاريين الميدانيين، صُمم لحل مشكلة عدم القدرة على متابعة الأعمال اليومية في مواقع المشاريع بشكل دقيق وموثوق.

**هذا النظام ليس مجرد حضور وانصراف**، بل هو منصة متطورة لتوثيق الأنشطة الفعلية، قياس نسب الإنجاز، وإنتاج تقارير إدارية شاملة تساعد في اتخاذ القرارات الاستراتيجية.

## ✨ الميزات الرئيسية

### 👥 إدارة المستخدمين والأدوار
- نظام أدوار متكامل (HR و Consultant)
- صلاحيات مرنة ودقيقة لكل دور
- إدارة كاملة للاستشاريين (إنشاء، تعديل، إيقاف، تفعيل)

### 🗺️ إدارة المواقع والمشاريع
- إنشاء وإدارة مواقع العمل
- تتبع زيارات المواقع اليومية
- إحصاءات دقيقة عن المواقع المزارة وغير المزارة

### 🧩 نظام المهام الديناميكي (Task Builder)
- **إنشاء مهام ديناميكياً** دون الحاجة إلى تعديل برمجي
- نوعان من المهام:
  - **المهام اليومية (Daily Tasks)** – تدخل في حساب نسبة الإنجاز
  - **المهام حسب الحاجة (On-Demand Tasks)** – أعمال إضافية خارج التقييم الأساسي
- دعم أنواع متعددة من حقول الإدخال:
  - اختيار (Choice / Checkbox)
  - نص (Text / Textarea)
  - أرقام وتواريخ
  - رفع صور وملفات
- **حقول شرطية (Conditional Fields)** تظهر بناءً على اختيارات المستخدم
- تخصيص المهام لمواقع محددة أو استشاريين معينين

### 📅 إدارة العمل والحضور
- جداول عمل فردية لكل استشاري
- احتساب تلقائي للحضور والغياب
- إدارة الإجازات والعطل الرسمية
- تقارير حضور دقيقة

### 📊 نظام الأداء والتقارير
- حساب فوري لنسبة الإنجاز اليومية
- لوحة تحكم للإدارة تعرض مؤشرات الأداء الحيوية
- تقارير متعددة:
  - أداء الاستشاريين (يومي، شهري، سنوي)
  - زيارات المواقع
  - المهام الإضافية
  - الحضور والغياب
- تصدير التقارير بصيغ (PDF, Excel, CSV)

### 🎨 تصميم واجهات (Spatial UI)
- نظام تصميم زجاجي حديث (Glassmorphism)
- دعم كامل للوضع المظلم (Dark Mode)
- واجهات تفاعلية سلسة مع Inertia.js
- تجربة مستخدم مريحة وسريعة

### 🔒 الأمان والتدقيق
- توثيق جميع العمليات الحساسة (Audit Log)
- حماية البيانات التاريخية من التعديل غير المصرح به
- صلاحيات دقيقة ومتحكم بها

## 👤 أدوار المستخدمين

### 👨‍💼 HR / Administrator
يمتلك صلاحيات كاملة لإدارة النظام:
- إدارة الاستشاريين والمواقع والمهام
- إنشاء جداول العمل والإجازات والعطل الرسمية
- متابعة أداء الاستشاريين
- استخراج التقارير والتحليلات

### 🧑‍🔧 Consultant
يقوم بتسجيل أعماله اليومية داخل المواقع:
- إنشاء سجل يومي
- اختيار مواقع العمل
- تنفيذ المهام اليومية والمهام حسب الحاجة
- كتابة الملاحظات ورفع الصور
- متابعة أدائه الشخصي

## 🛠️ التقنيات المستخدمة

### Backend
- **Laravel 10.x** – الإطار الأساسي
- **Repository Pattern** – فصل منطق الأعمال عن وحدات التحكم
- **spatie/laravel-permission** – إدارة الصلاحيات والأدوار
- **spatie/laravel-query-builder** – بناء استعلامات مرنة للتقارير
- **owen-it/laravel-auditing** – توثيق التعديلات والحفاظ على السجل التاريخي
- **barryvdh/laravel-dompdf** – تصدير التقارير بصيغة PDF

### Frontend
- **Vue.js 3** – إطار الواجهات الأمامية
- **Inertia.js** – ربط سلس بين Backend و Frontend
- **Tailwind CSS** – تصميم سريع ومتناسق
- **Spatial UI System** – نظام تصميم زجاجي حديث

### Testing & Quality
- **Pest** – إطار اختبار سهل وقوي
- **Larastan** – تحليل ثابت للكود
- **Mockery** – محاكاة الكائنات أثناء الاختبار

## 🚀 البدء السريع (Quick Start)

### المتطلبات الأساسية
- PHP >= 8.1
- Composer
- Node.js >= 18
- MySQL / PostgreSQL

### خطوات التثبيت

```bash
# 1. استنساخ المستودع
git clone https://github.com/your-username/fcpms.git
cd fcpms

# 2. تثبيت الحزم الخلفية
composer install

# 3. إعداد بيئة التطوير
cp .env.example .env
php artisan key:generate

# 4. تثبيت الحزم الأمامية
npm install

# 5. تجميع الواجهات
npm run build

# 6. تشغيل الهجرة (Migrate) وزرع البيانات الأولية
php artisan migrate --seed

# 7. تشغيل الخادم
php artisan serve
npm run dev
```

- **كلمة المرور:** `password`
